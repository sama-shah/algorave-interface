page live here: [https://github.com/sama-shah/algorave-interface](https://sama-shah.github.io/algorave-interface/)
inspired by algo rave artists like dj_dave on instagram and charstiles, i am using strudel.cc's docs as a reference and turning it into a more accessible and easy to learn interface so that you can make live music. 

although this strays away from the point of algo raving which is to be live, i wanted to add a recording feature so that you can record and save your favorite snippets in case you want to build on it in a DAW applcation and make a replay-able song.
